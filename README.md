# ربات دانلودر تلگرام (یوتیوب / اینستاگرام / توییتر)

ربات ساده‌ای که لینک ویدیو/پست می‌گیره و فایل رو برات تو تلگرام می‌فرسته.
نیازی به هاست نداره — فقط کافیه یک بار روی سیستم خودت (ویندوز/مک/لینوکس) اجرا کنی و تا وقتی که روشنه، ربات فعاله.

## ۱. ساخت ربات در تلگرام
1. به [@BotFather](https://t.me/BotFather) تو تلگرام پیام بده.
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم دلخواه بده.
3. یک توکن شبیه این بهت می‌ده: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

## ۲. نصب پیش‌نیازها
نیاز به **Python 3.9 یا بالاتر** داری.

```bash
pip install -r requirements.txt
```

همچنین برای تبدیل صدا (گزینه MP3) باید **ffmpeg** نصب باشه:

- ویندوز: از [ffmpeg.org](https://ffmpeg.org/download.html) دانلود کن و به PATH اضافه کن (یا با `winget install ffmpeg`)
- مک: `brew install ffmpeg`
- لینوکس (اوبونتو/دبیان): `sudo apt install ffmpeg`

## ۳. وارد کردن توکن
یکی از دو روش:

**روش ساده:** فایل `bot.py` رو باز کن و این خط رو ویرایش کن:
```python
BOT_TOKEN = os.environ.get("BOT_TOKEN", "PUT-YOUR-TOKEN-HERE")
```
و `PUT-YOUR-TOKEN-HERE` رو با توکن واقعی خودت جایگزین کن.

**روش بهتر (امن‌تر):** به‌جای ویرایش کد، قبل از اجرا متغیر محیطی ست کن:

لینوکس/مک:
```bash
export BOT_TOKEN="توکن-تو-اینجا"
```
ویندوز (PowerShell):
```powershell
$env:BOT_TOKEN="توکن-تو-اینجا"
```

## ۴. اجرا
```bash
python bot.py
```
وقتی پیام `✅ ربات روشن شد...` رو دیدی، ربات فعاله. حالا برو تو تلگرام با ربات خودت `/start` بزن.

> ⚠️ تا وقتی این پنجره/ترمینال باز و این اسکریپت در حال اجراست ربات فعاله. اگه ببندیش، ربات خاموش میشه.
> برای این‌که همیشه روشن بمونه (بدون نیاز به باز نگه داشتن سیستم)، می‌تونی بعداً روی یک سرور کوچیک یا سرویس‌های رایگان مثل Railway / Render اجراش کنی — ولی برای تست و استفاده شخصی همین روش محلی کافیه.

## اگه دانلود از یوتیوب با خطا مواجه شد (خیلی رایجه)

یوتیوب این روزها اغلب جلوی دانلود بدون لاگین رو می‌گیره و خطایی شبیه این می‌ده:
`Sign in to confirm you're not a bot`

راه‌حل: یک فایل کوکی از مرورگر خودت (که توش لاگین یوتیوب هستی) بساز و کنار `bot.py` بذار:

1. اکستنشن [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) رو روی کروم نصب کن.
2. وارد youtube.com شو (با اکانت گوگل خودت لاگین باش).
3. روی آیکون اکستنشن بزن و فایل `cookies.txt` رو دانلود کن.
4. این فایل رو کنار `bot.py` بذار (یا اگه روی Railway هستی، محتوای فایل رو به یک فایل به اسم `cookies.txt` تو ریپوی گیت‌هابت اضافه کن).

> ⚠️ این فایل اطلاعات نشست (session) اکانت گوگلته — جایی آپلودش نکن که عمومی/public باشه (ریپوی گیت‌هاب رو حتماً private بذار).

بعد از آپدیت کد (که الان این قابلیت رو بهش اضافه کردم)، اگه این فایل کنار بات باشه، خودکار ازش استفاده می‌کنه.

## محدودیت‌ها
- تلگرام اجازه نمی‌ده ربات‌های معمولی فایل بزرگ‌تر از ۵۰ مگابایت بفرستن؛ برای ویدیوهای بزرگ، ربات به‌صورت خودکار کیفیت رو پایین‌تر (تا ۷۲۰p) انتخاب می‌کنه.
- دانلود از پست‌های خصوصی اینستاگرام (که نیاز به لاگین دارن) پشتیبانی نمی‌شه؛ فقط پست‌های عمومی.
- محتوای دانلودی ممکنه تحت کپی‌رایت باشه — مسئولیت استفاده از فایل‌ها با خودته.

## عیب‌یابی سریع
- **خطای "Unsupported URL"**: لینک رو کامل و درست کپی کن (نه کوتاه‌شده با واسطه‌های دیگه).
- **خطای مربوط به ffmpeg**: مطمئن شو ffmpeg نصب و در PATH سیستم قابل‌دسترسیه (با دستور `ffmpeg -version` چک کن).
- **کتابخونه yt-dlp قدیمیه و لینک جدید کار نمی‌کنه**: به‌روزش کن:
  ```bash
  pip install -U yt-dlp
  ```
