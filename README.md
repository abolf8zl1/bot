# 📥 Instagram Downloader Bot | ربات دانلودر اینستاگرام

یک ربات تلگرامی ساده و سبک برای دانلود پست‌ها و ریلزهای عمومی اینستاگرام، مستقیم داخل تلگرام.

لینک پست رو برای ربات بفرستی، خودش فایل (عکس یا ویدیو) رو دانلود می‌کنه و برات می‌فرسته. همین!

---

## ✨ امکانات

- دانلود پست‌ها و ریلزهای عمومی اینستاگرام
- تشخیص خودکار نوع فایل (عکس یا ویدیو) و ارسال متناسب با همون فرمت
- بدون نیاز به دیتابیس یا زیرساخت پیچیده
- قابل اجرا هم روی سیستم شخصی، هم روی سرویس‌های رایگان مثل Railway

## 🧰 تکنولوژی‌ها

- Python 3.9+
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp)

## 🚀 نصب و اجرا

### ۱. کلون کردن ریپو
```bash
git clone https://github.com/abolf8zl1/downloaderbot.git
cd downloaderbot
```

### ۲. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۳. ساخت ربات در تلگرام
1. به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم دلخواه انتخاب کن.
3. یک توکن شبیه این دریافت می‌کنی: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### ۴. تنظیم توکن
توکن رو به‌عنوان متغیر محیطی ست کن (هیچ‌وقت مستقیم تو کد ننویس، مخصوصاً تو ریپوی پابلیک!):

**لینوکس / مک:**
```bash
export BOT_TOKEN="توکن-تو-اینجا"
```
**ویندوز (PowerShell):**
```powershell
$env:BOT_TOKEN="توکن-تو-اینجا"
```

### ۵. اجرا
```bash
python bot.py
```
وقتی پیام `✅ ربات روشن شد...` ظاهر شد، ربات آماده‌ست. برو تو تلگرام با ربات خودت `/start` بزن.

## ☁️ دیپلوی روی Railway (بدون نیاز به هاست شخصی)

این پروژه همراه با `Procfile` و `nixpacks.toml` آماده‌ست:

1. ریپو رو فورک یا کلون کن.
2. تو [railway.app](https://railway.app) یک پروژه جدید از روی این ریپو بساز.
3. تو تب **Variables**، متغیر `BOT_TOKEN` رو با توکن ربات‌ت ست کن.
4. Railway خودکار build و deploy می‌کنه.
